# University Logos

Place university logo images in this folder with the following names:

- `purdue.png` - Purdue University logo
- `fiu.png` - Florida International University logo
- `urmia-tech.png` - Urmia University of Technology logo
- `urmia.png` - Urmia University logo

**Recommended specifications:**
- Format: PNG with transparent background
- Size: 100x100 pixels or larger (square format)
- File size: Under 50KB each

The logos will be automatically displayed in the Education & Experience timeline sections.
